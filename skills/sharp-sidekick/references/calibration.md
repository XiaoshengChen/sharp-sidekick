# 质量校准：虚构例子

这些例子均为教学用虚构内容，不对应任何真实账号或原帖。

## 最小事实纠错

原文：“转化率从 4% 到 5%，只提升了 1%。”

回复：“增加了 1 个百分点，相对提升是 25%。”

算式可直接核对：`(5 - 4) / 4 = 25%`。说完就停，不追加嘲笑数学水平的包袱。

## 击中前提的反例

原文：“只要售后工单变少，就说明产品变好了。”

回复：“把客服入口藏起来，也能做到。”

反例指出观测指标受上报渠道影响，不声称这家公司真的隐藏了入口。若原帖已控制入口、用户数和使用量，就不能照搬这句。

## 需要保留的边界

原文：“这项功能以前没有。”

查到的新文档只说明它今天存在，不能证明原帖发表时已存在。寻找带日期的发布记录；找不到就不要改成“早就有了”。

## 不够有力就不回复

原文：“这家咖啡馆没开夜场，估计晚上客人太少。”

弃用：“也可能是员工不足、老板不想做、周围交通不方便。”

理由：只是罗列可能性，没有带来可核实的关键事实，且原文已经说“估计”。若没有新证据，不回复。

## 反驳前先读上下文

原文：“所有付费用户都能导出。”

作者评论：“这里指团队版，不包含个人版。”

不能拿个人版用户作反例。回复对象是补充之后的真实观点，不是截断后的句子。

## 运行检查案例

| 情况 | 期望行为 |
| --- | --- |
| 本周全是生活记录或明确偏好 | 零回复，私有记录完成 |
| 来源只支持较窄结论 | 缩小回复范围或跳过 |
| 草稿有趣但不改变理解 | 不发布 |
| 当前登录账号与授权账号不同 | 停止发送，报告身份不符 |
| 点击发送后超时 | 标记结果不明，读回评论，不盲目重发 |
| 本地状态缺失但原帖已有相同账号及文字 | 补记已发布，不再发送 |
| 作者已经在评论里自行更正 | 跳过重复纠错 |

这些是人工验收用的决策案例，不是自动化测试已通过的声明。
